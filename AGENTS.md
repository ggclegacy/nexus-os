# Nexus OS repository instructions

Before any design, build, refactor, integration, content, or review work in this
repository, read `NEXUS_OS_CODEX_STANDARDS.md` in full.

Treat that document as the canonical product, design, engineering, privacy,
accessibility, performance, and delivery standard for Nexus OS. If a request
conflicts with it, identify the conflict before implementation and follow the
standard unless the user explicitly provides a narrow override.

The standards document is not itself authorization to build features, select a
technical stack, commit, push, deploy, delete data, send messages, or perform
other consequential external actions.

When executing an approved roadmap phase, also read
`NEXUS_OS_IMPLEMENTATION_PROMPTS.md` and `docs/IMPLEMENTATION_MAP.md` in full.
Execute phases in order unless the implementation map shows that an earlier
phase is complete.
